# Banco Python

Este projeto é uma aplicação de gerenciamento bancário em Python. Ele permite a criação de clientes, contas e o registro de transações, como depósitos e saques.

## Estrutura do Projeto

```
banco-python
├── src
│   ├── models
│   │   ├── __init__.py
│   │   ├── cliente.py
│   │   ├── conta.py
│   │   └── historico.py
│   ├── interfaces
│   │   ├── __init__.py
│   │   └── transacao.py
│   └── main.py
└── README.md
```

## Como Usar

1. **Instalação**: Certifique-se de ter o Python instalado em sua máquina. Clone este repositório e navegue até o diretório do projeto.

2. **Executar o Projeto**: Execute o arquivo `main.py` para iniciar a aplicação.

3. **Funcionalidades**:
   - Criar clientes com informações pessoais.
   - Criar contas bancárias.
   - Registrar transações de depósito e saque.
   - Manter um histórico de transações.
